# HTML Week 1 Assignment

This project is a simple **HTML document** created as part of my **Week 1 HTML Assignment**.  
It demonstrates the basic structure of an HTML5 page and includes key elements like headings, paragraphs, lists, links, and a navigation menu.

---

## 📄 Features
- **HTML5 Document Structure**
  - `<!DOCTYPE html>` declaration
  - `<head>` with metadata and responsive `<meta viewport>`
- **Header Section**
  - Main heading (`<h1>`) and subheading (`<h2>`)
  - Navigation menu inside `<nav>` using an unordered list
- **Body Content**
  - Paragraphs introducing the assignment
  - Unordered list of fruits and ordered list of steps
- **Links Section**
  - Link to an external **image**
  - Link to an **external website**
- **Footer Section**
  - Thank-you note to conclude the page

---

## 💻 How to View
1. Clone or download the repository.
2. Open the `index.html` file in any web browser.

---

## 📚 Learning Goals
This assignment helped me understand:
- The structure of an HTML document.
- How to use **headings, paragraphs, lists, and links**.
- The purpose of **semantic tags** like `<header>`, `<nav>`, and `<footer>`.
- Basic **accessibility and readability** in HTML.
